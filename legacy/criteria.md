# A股多因子模型评价标准

## 月度回测口径

- 每月调仓，月末产生信号，下一个市场交易日收盘成交；双边成本为换手率乘以0.3%。
- 按时间滚动训练，训练样本至少48个月；当前训练代码按收益标签完成日剔除尚未兑现的样本。
- A股组合为前30只，不额外混合因子或平滑分数。
- 月度评价基准为当期股票池等权收益。
- 最后12个月单独展示，但已被查看或参与历史选型，不能作为新的独立留出检验。

## 评价门槛

| 指标 | A股 |
| --- | --- |
| 月度排名相关性 IC 均值 | ≥0.03 |
| IC均值／标准差 | ≥0.30 |
| IC为正月份占比 | ≥55% |
| 组合算术年化超额（扣费后，相对池内等权） | ≥8% |
| 超额信息比率 | ≥0.5 |
| 相对池内等权基准的月胜率 | ≥55% |
| 选股命中率（跑赢池中位数） | ≥55% |
| 年化换手 | ≤30倍 |
| 历史滚动预测月份数 | ≥36 |

九项全部达到才判定为通过。跑赢池均值的选股命中率同时报告，作为参考项，不参与九项判定。

## QVeris成交模拟口径

A股展示逐日账户、0.15%／0.30%／0.50%每边费用情景、复合年化收益、每日回撤、沪深300价格指数基准、交易约束和数据缺项。具体回放区间必须随结果展示。

复合年化与月平均收益乘以12的算术年化分开；每日回撤与月末回撤分开。账户执行缺项和理想等权比较缺项分别披露。
